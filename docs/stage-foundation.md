# 舞台基础打磨与验收

## 第一批：执行可靠性

已实现：

- 精确 Slot 校验、动态抢格/脚底碰撞、挡路重寻路、移动期限与排队释放；
- ShowRunner 独立于 Vue/Phaser，负责准备、场景、beat 和 cue 的生命周期；
- 演出暂停/继续/取消，统一暂停角色、镜头、音频、wait/hold；
- 镜头实际完成后推进、后台 cue 异常传播、提前验证内容引用；
- 自动化覆盖交叉行走、四人对向通行、动态障碍、永久阻挡、精确站位、取消/暂停、晚到音频与内置短剧真实地图上的全指令执行。

不改变 base20 动画机制，不修改 Agent 后端，不新增运行时依赖。Pages 仍为无后端 playground。

## 手工验收

```bash
VITE_STAGE_MODE=playground pnpm dev
```

1. 播放内置 JSON 短剧；对白、运动后对白与原音频都应正常。
2. 在一句音频中途暂停：人物/镜头/声音停住。等待几秒后继续：从暂停位置接着播，不从头重复、不跳到下一句。
3. 在镜头平移或人物行走中暂停；再继续，确认运动继续且之后的 beat 正常推进。
4. 切到其他标签页再返回：应显示暂停状态，点击继续。
5. 在加载、对白、移动、暂停时分别点击“结束演出”：停止声音和剧本任务，恢复 WASD 和角色基础操作；再次运行应可从头开始。
6. 验证多人跟随和 Portal 往返未回归；留守者仍在原图。全封闭的窄道允许明确失败，不要求角色穿过彼此。

自动验证：`pnpm check`。内置短剧集成测试使用真实内容和 Runtime，不代替浏览器画面、听感和后台标签页的实机验收。
