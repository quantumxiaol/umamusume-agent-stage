# 舞台地图覆盖与环境表现

这份清单用于回答两个不同的问题：

1. 实时 Stage 里，角色目前能在哪些可行走、可寻路、可演出的场景活动；
2. `umamusume-anime` 已使用过哪些背景语义，可作为新地图的需求来源和视觉参考。

`umamusume-anime` 的平面背景不能直接等同于 Stage 地图。Stage 地图还需要世界尺寸、碰撞、Anchor、Spawn、Portal 和镜头可视范围。Anime 背景适合复用为地点目录、构图参考、色调参考，以及以后视频演出中的过场镜头。

## 当前 Stage 覆盖

当前共有 9 张可行走地图，并已组成连续的 Portal 网络。

| 场景组 | 已覆盖地图 | 当前可用演出点 |
| --- | --- | --- |
| 学院室外 | 学院正门与大道、学生广场、校舍前庭 | 正门集合、访客接待、喷泉会面、钟楼及东西翼集合 |
| 学院室内 | 主校舍内部 | 教室、图书馆、训练员室门口，入口大厅与楼梯；目前还没有进入房间后的独立空间 |
| 训练设施 | 综合训练场、室内训练馆 | 芝地、泥地、冲刺、热身、力量、有氧、泳池和恢复训练集合点 |
| 日常生活 | 餐厅与商店区、宿舍生活区 | 取餐、聚餐、小卖部、咖啡、露台、宿舍入口、洗衣和庭院 |

这套地图已经足够验证实时 RPG 的核心闭环：找人、走近、跟随、停止跟随、对话、切换地图和切换镜头。它还不够承载完整的校园日常或比赛短剧。

## Anime 素材给出的场景信号

`umamusume-anime/scripts/background_catalog.json` 当前有 370 个背景别名。对 `draft/**/*script*.json` 做去重到“使用该背景的剧本文件数”后，最频繁的地点包括：

- 训练员室：白天/早晨 30 个剧本文件，夜间 21 个；
- 赛道：白天 14 个，黄昏 11 个，另有夜间、雨天、训练场和训练隧道；
- 剧场舞台、商业街、学校走廊和赛场看台/赛道边：各约 8–9 个剧本文件；
- 宿舍房间、公共休息室、食堂、图书馆、学生会室也反复出现；
- 河边、森林、神社、海边、观景台等承担较多情绪戏和校外剧情。

这里的计数包含同一作品的 retry 版本，因此只用于排优先级，不作为严格的作品统计。

## 建图优先级

### P0：补齐日常对话闭环

1. **训练员室**：当前最高频、也是用户与角色接任务、复盘训练、进行长对话的自然出生点。建议先做一张小而精的室内地图，至少包含办公桌对坐、窗边、沙发/茶几和门口四组 Anchor。
2. **教学楼房间层**：把现有“门口”变成可进入的教室、图书馆、学生会室和医务室。可以先做一张多房间组合地图，等演出需求增加后再拆图。
3. **宿舍内部**：公共休息室和房间比当前宿舍外部更适合私密对话；洗衣房可继续留在现有生活区。

### P1：补齐赛马娘核心世界观

4. **赛马场综合区**：看台/赛道边、Paddock、赛前准备室和赛场大厅。建议拆成 2–3 张 Portal 相连的地图，不要塞进一张超大地图。
5. **训练隧道与起跑准备区**：连接现有综合训练场，可承载训练前后和临场紧张感。
6. **舞台与后台**：用于胜者舞台、演唱会和公开活动；Anime 素材中的 `theater_stage`、`stage_backstage_*` 可以作为构图参考。

### P2：扩展 RPG 日常和情绪场景

7. **商业街/车站/咖啡店**：把河边的“城市扩展点”接到商业街，形成校外生活环。
8. **公园/神社/森林步道**：低成本复用自然 tileset，能覆盖大量安静或节日剧情。
9. **海边与夏合宿**：使用频率高，但属于独立章节，适合在校园闭环稳定后增加。
10. **天台或观景台**：面积小、构图强，适合夜景和爱慕织姬等星空主题短剧。

## 昼夜与天气

昼夜和简单天气不需要复制碰撞地图。建议把它们作为渲染环境状态，而不是新的 `scene_id`：

```json
{
  "time_of_day": "evening",
  "weather": "rain",
  "intensity": 0.55,
  "transition_ms": 1200
}
```

第一阶段只做表现层：

- `day / evening / night`：颜色分级、亮度和环境遮罩；
- `clear / rain / snow`：相机空间粒子或轻量动画遮罩；
- 切换不改变导航网格、Anchor、Portal 或角色坐标；
- 气泡、角色名和调试 UI 不参与变暗，确保可读性；
- 小地图只显示轻微色调，不绘制密集雨雪粒子。

第二阶段再由个别地图提供专用灯光、窗户和积雪 tile override。Anime 中已有的 `*_evening`、`*_night`、`*_rain`、`*_snow` 背景可以为这些 preset 提供色板，但不应要求每个 Stage 地图复制四份。

实时对话阶段先保留人工环境 preset；等动作执行稳定后，再给 Agent Stage Director 和离线演出脚本增加 `environment.set` cue。这样可以避免现在扩协议时再次把主线带偏。
